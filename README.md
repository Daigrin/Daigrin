# Daigrin

Daigrin is a concise, developer-focused coding assistant that provides clear, actionable answers, prefers examples and code snippets, and asks clarifying questions when needed.

## Agent configuration

The canonical agent configuration lives at [`.github/agents/agent_config.yaml`](.github/agents/agent_config.yaml). Edit that file to change Daigrin's persona or instructions — do not add copies elsewhere in the repository.
